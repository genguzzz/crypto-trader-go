# 模拟交易与策略 [模拟交易](/trading)

**全部是模拟盘**：不会向 OKX 下任何真实订单，也不读 OKX 账户（新建账户里的“实盘”选项是灰的，需单独授权）。成交按真实盘口（实时）或 K 线（回测）模拟，计入手续费、滑点和资金费。

交易页子标签：账户（`/trading`）、策略库（`/trading/strategies`）、待确认（`/trading/prompts`）、AI 决策（`/trading/ai`）。新建账户在 `/trading/new`。

## 账户

- 账户 = 一笔入金（模拟 USDT）+ 一组硬性风控规则；策略实例挂在账户下，多个策略共享资金和风控。
- 类型：**实时模拟**（实时行情持续运行，可继续入金）/ **历史回测**（选起止时间按历史 K 线重放，最长 365 天，入金在区间开始时一次到账，结束后出报告，可重跑/取消）。
- 账户页：权益曲线（1D/7D/30D/全部）、持仓、委托、成交、流水、信号、策略实例；可手动平一个或全部仓位、入金、改风控、归档。
- **权益** = 现金 + 持仓保证金 + 未实现盈亏（按标记价，v1 标记价 = 最新成交价）；**可用** = 未被保证金占用的现金。
- **持仓**：逐仓；强平价按 0.5% 维持保证金率估算，标记价穿过时整仓按强平价平掉、保证金损失。同一实例同一合约只能有一个方向。
- **委托**：含等待触发的止损/止盈（OCO：一个成交另一个自动撤）。**流水**：入金、手续费、资金费、已实现盈亏、强平。

### 风控规则（策略和 AI 都不能绕过）

| 项 | 含义 |
|---|---|
| 最大持仓数 | 同时持有的合约个数 |
| 最大杠杆 | 逐仓杠杆上限（信号要求更高时截断）；系统还会降低杠杆，让强平价至少在止损外侧 25% 止损距离处 |
| 单笔风险 | 信号强度为 1 时止损被打掉的权益比例（1%–500%，对数滑杆） |
| 单合约上限 | 一个合约占用保证金 ≤ 权益的该比例 |
| 日亏损熔断 | 当日（UTC+8）已实现 + 未实现亏损达到权益比例后，当天不再接受开仓，次日自动恢复；平仓、止损不受影响；0 = 不熔断 |
| 冷却时间 | 某合约平仓后多少分钟内不再开同一合约 |
| 必须带止损 | 开仓信号没有止损价直接拒绝 |
| 滑点容忍 | 市价入场最差成交价 = 中间价 × (1 ± bp/10000)，吃不到的部分取消；止损止盈触发后按市价，不受此限 |
| 手续费 | taker / maker，默认 5 bp / 2 bp；资金费按真实结算记录收取 |
| 需要确认 | 关闭 / 仅开仓 / 全部；确认超时（秒）与超时默认（跳过 / 执行） |

**仓位公式**：数量 = 权益 × 单笔风险 × 信号强度 × 缩放 ÷ (|入场 − 止损| × 合约面值)，再受杠杆、单合约上限约束，按最小下单量向下取整，不足最小下单量则拒绝。

## 策略实例

实例 = 策略代码的一个已发布版本 + 参数 + 交易标的 + 执行方式；同一策略可以不同参数挂多次。修改参数/标的/执行方式会生成新配置版本（v2、v3…），历史信号保留原版本。

- **交易标的**：固定列表（≤ 50 个合约），或动态筛选——“活跃池按评分”（所选规则的多头分 / 空头分 / 较强一侧，取前 N，可设最低分）或“全市场按成交额”（加密永续按 12h 成交额排名，不能用评分）。按“重新筛选”间隔更新；被移出的合约不再开新仓，已有持仓照常管理。分数未验证，只是排序依据。
- **执行方式**：
  - **自动**：信号直接经风控与仓位计算下单。
  - **AI 审核**：先把信号、账户与持仓、行情摘要、该策略近期决策结果和经验文档交给 AI；AI 回答执行或跳过，可缩小仓位、调整止损止盈，但不能放大仓位、不能绕过风控、不能直接改参数。只审核开仓信号。AI 不可用（未授权、代理不通）或超时 → 按跳过处理。AI 的“执行”之后仍要过风控，结果可能是“风控拒绝”。回测里 AI 审核按“自动”处理（AI 可能记得历史，属于前视）。
  - **只记录**：只记录信号和去向，从不下单，用来观察新策略。
- 顺序：执行方式（AI 审核）→ 人工确认（若开启）→ 风控 → 仓位 → 下单。
- **状态**：未启动 / 运行中 / 已暂停（不处理新 K 线，持仓与止损照常）/ 故障（进程超时或连续出错，自动重启 3 次后停止）/ 已停止。**停止策略不会平仓**，需要时手动平仓。
- **信号去向**：已下单、风控拒绝（原因见“结果”）、AI 跳过、用户跳过、过期（等待确认或 AI 超过有效期 TTL）、只记录。信号时间是对应 K 线的收盘时间（交易所时间）。

## 人工确认 `/trading/prompts`

开启确认的账户，符合条件的信号在下单前停在“待确认”，同时推到 Telegram（设置 → 交互通道）。任一处回答即可：**执行**（正常仓位，仍过风控）/ **半仓** / **跳过**。超时按“超时默认”。回测不等待确认。

## AI 决策 `/trading/ai`

每次 AI 审核的记录（含完整上下文、模型、耗时、费用）。**参数建议**：AI 提出、主人批准后才生效（生成新配置版本）。**经验文档**：每天（00:05 UTC+8）对有新决策的策略，让 AI 读取过去的决策和平仓结果提炼一份简短文档，之后审核会带上；每次生成新版本，旧版本保留。AI 授权在 [设置](/settings) → AI 授权；AI 只经代理访问，不直连。

## 回测报告 `/trading/backtests/<id>`

- 成交模型：信号在下一根**基础 K 线**开盘价成交（± 半个点差，按 2 bp + 1 跳）；基础 K 线：策略周期与定时器都 ≥ 1H 时用 1H，否则用 1m。同一根内止损优先于止盈；手续费、真实资金费计入。
- **净收益** = 期末权益 − 入金（含未实现）；**毛收益** = 净收益 + 手续费 − 资金费。
- 一笔交易 = 同一策略在同一合约从开仓到完全平仓，盈亏 = 已实现 − 手续费；胜率、盈亏比按交易算，无交易为“—”。
- **夏普** = 每日（UTC+8）权益收益均值 ÷ 标准差 × √365，不足 5 天不计算。另有最大回撤、换手、按合约贡献（已实现 − 手续费 + 资金费）。
- 交易浏览器：组合视角（权益曲线 + 每笔交易气泡，角标 止/盈/爆/手）与币对视角（K 线上标出每次成交与止损止盈线）。
- 回测只说明这组参数在这段历史的表现；调参越多越易过拟合，应再用实时模拟在样本外观察。

## 策略库 [策略](/trading/strategies)

- 策略是用 `ctg` SDK 写的 Python 类：声明参数、标的、周期，在每根已收盘 K 线上返回信号。策略只发信号，下单、风控、仓位由账户统一处理；策略进程在无网络的隔离容器里运行。
- **内置策略**（只读示例，可“复制为新策略”）：演示脉冲 `demo-pulse`、大币均线趋势 `majors-trend`、币池残差反转 `pool-reversal`、山寨币状态趋势 `alt-regime-trend`。
- **我的策略**：网页编辑器自动保存草稿；“试运行”用草稿回放最近 1–60 天（默认 14 天，≤ 90 秒，结果不保留）；“发布”生成不可变版本后才能回测和挂到账户。
